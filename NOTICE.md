# Notice: educational use only

**quick-gateway is an unofficial, independent project published for educational and research purposes.**
It exists to show how an API gateway can be built on Cloudflare Workers: protocol translation between
OpenAI and Anthropic formats, streaming over WebSockets, encrypted secret storage in KV, OAuth with PKCE,
and a small admin dashboard.
